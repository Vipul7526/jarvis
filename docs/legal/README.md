# Legal Center Documents

The `legal/` folder contains the versioned J.A.R.V.I.S. Privacy Policy, Terms & Conditions, User Agreement, Software License, Third-Party Licenses, AI Disclaimer, and Device Control Disclaimer.

## Setup guide

Expose these documents in the application Legal Center with view, search, copy, print, and export support where available. Every document must include a version and effective date. Store the exact accepted versions, user ID, acceptance time, and application version on the backend.

## Review and release

The acceptance checkbox must never be selected automatically. Material changes require a new version and re-acceptance where applicable. Replace placeholder third-party license metadata with exact resolved dependency information before release. These drafts should receive jurisdiction-specific legal review before public distribution.
