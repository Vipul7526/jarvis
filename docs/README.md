# Documentation

The `docs/` folder contains J.A.R.V.I.S. architecture, implementation status, platform integration, delivery, and legal-center documentation.

## Guide

Start with `ARCHITECTURE.md` for system boundaries, `PLATFORM_INTEGRATION.md` for client and deployment work, and `IMPLEMENTATION_STATUS.md` for verified versus unavailable components. `DELIVERY_REPORT.md` summarizes the current implementation slice.

Documentation must distinguish implemented behavior from planned work. Security, privacy, legal, and platform claims should be updated whenever the implementation changes.
