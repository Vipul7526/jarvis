# Flutter Client

This folder contains the first Flutter client scaffold for Android and future desktop targets. It renders the J.A.R.V.I.S. readiness surface and keeps planned capabilities visibly separate from verified ones.

## Setup

Install Flutter 3.19 or newer, then run `flutter pub get` and `flutter run`. The client is not a signed production APK yet; pairing, voice, permissions, and backend transport still require integration work.
